# Агенты и workflow

Любой запуск агента или workflow требует моего подтверждения: Agent и Workflow стоят в permissions.ask в .claude/settings.json. Этот файл — о том, когда запуск вообще предлагать.

## Когда предлагать
- Задача распадается на независимые части по непересекающимся файлам, и каждая часть — больше трёх файлов.
- Аудит, ревью, поиск по всему репозиторию — агентом auditor, он только читает.
- Независимая перепроверка результата, который иначе проверил бы сам автор.

## Когда не предлагать
- Задача меньше чем на три файла — один контекст.
- Правка src/core/model/**, src/protocol/** и общих типов — только основной контекст.
- Поиск, который решается одним grep или чтением пары файлов.
- Agent teams не используем.

## Перед запросом
- Одной строкой: сколько агентов, зачем, какие файлы, почему они не пишут. Решение по лимиту — моё, в окне подтверждения.

## Пределы
- Одновременно не больше 4 (потолок в .claude/settings.json), за прогон не больше 8.
- Параллельная запись — только в отдельных worktree и с моего слова.
- Сессия может идти в ultracode — это мой выбор. Workflow и агенты всё равно только по правилам этого раздела: после моего подтверждения, что лимита не меньше половины.
